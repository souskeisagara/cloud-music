# Cloud Music for MikuTV

A MikuTV content source plugin for music browsing, playlists, synced bilingual lyrics, lossless audio streaming, MV switching, and background listening on Apple TV.

## Features
- QR-code sign-in with personal playlist synchronization and play history
- Personalized recommendations, charts, genre playlists, and full-text search
- Direct audio streaming (`.mp3` / `.flac`) with seamless Audio ↔ MV switching
- Synced bilingual lyrics rendered on MikuTV's ambient audio stage
- Loop & shuffle playback modes (`playback.modes`) and playlist **Play All**
